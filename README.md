# Capability Fix Revived

## How to use:
- **Start Recording:** Run /capability_fix_revived toggle_recording. You will see a [🔧] Capability Fix | recording has started message.



- **Play the Game:** Let the server run for a while (or perform laggy actions) so the mod can track which capabilities are being fetched the most.


- **Generate Report:** Run /capability_fix_revived generate_report.

*The mod might pause for a moment to finalize the data. It will automatically stop recording for you.*


- **Configure:** Open config/capability_fix_revived/reports/capability_report.txt.



- **Copy the capability IDs:** (e.g., com/hollingsworth/arsnouveau/api/mana/IManaCap) into your config/capability_fix_revived/capability_fix_revived-common.toml whitelist.



- **Apply:** Run /capability_fix_revived reload_config ingame to apply the changes without restarting.
